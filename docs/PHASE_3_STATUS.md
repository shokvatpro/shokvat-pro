# حالة المرحلة 3 — البنية متعددة المستأجرين والمصادقة
آخر تحديث: 9 نوفمبر 2026

## ما تم ✅ — طبقة قاعدة البيانات (مختبرة على PostgreSQL 16 حقيقي)

### قاعدة Data Plane الإقليمية (`packages/db-tenant`)
- 20 جدولًا: الإعدادات، الفروع، الأقسام، الموظفون، الأدوار والصلاحيات، القنوات، أحداث المزودين، العملاء وهوياتهم، المحادثات، الرسائل، الملاحظات الداخلية، الردود الجاهزة، المواعيد وأحداثها، المهام، الموافقات، سجل التدقيق.
- **عزل المجمعات داخل محرك قاعدة البيانات:** RLS مفعّل و**مفروض (FORCE)** على كل الجداول، ودور التطبيق `sp_app` لا يملك أي جدول ولا يستطيع تجاوز RLS.
- **الفشل الآمن:** أي استعلام دون سياق مجمع يرمي خطأ بدل إرجاع بيانات.
- **مفاتيح أجنبية مركّبة `(tenant_id, id)`:** تحسين على الوثيقة الأصلية. فحص المفاتيح الأجنبية في PostgreSQL يتجاوز RLS، فالمفتاح العادي كان سيسمح لمجمع بربط سجله بعميل مجمع آخر؛ المفتاح المركّب يمنع ذلك.
- **نطاق الفرع:** الموظف المقيّد بفرع لا يرى محادثات أو رسائل أو مواعيد فرع آخر، ولا ينشئها.
- **سجل التدقيق والموافقات:** إضافة فقط — لا تعديل ولا حذف حتى من مالك الجداول.
- **الموافقة التسويقية:** دالة `can_send_marketing` — آخر موافقة تسويقية هي الحاكمة؛ موافقة الخدمة لا تفتح التسويق.
- **توجيه الـ webhooks:** دالة واحدة ضيقة (`resolve_channel_account`) تحدد مجمع الحساب الخارجي دون منح التطبيق أي تجاوز لـ RLS.
- **Idempotency:** الحدث الخارجي المكرر يُخزن مرة واحدة.
- بيانات وهمية: 3 مجمعات تجريبية + الأدوار الستة بمصفوفة الصلاحيات المعتمدة + محادثات ومواعيد.

### قاعدة Control Plane العالمية (`packages/db-control`)
- الدول السبع، العملات (3 خانات للدينار الكويتي والبحريني والعماني)، مناطق البيانات، المجمعات، الهوية، المستخدمون، MFA، الجلسات (تخزين hash فقط)، الباقات والحدود والمزايا، الأسعار، الاشتراكات، الفواتير، أحداث الدفع، الاستخدام المجمّع، منح وصول الدعم، سجل تدقيق المنصة.
- **بوابة الدولة:** لا يمكن إنشاء مجمع حقيقي في دولة غير مفتوحة، ولا في منطقة بيانات غير منطقة دولته.
- أسعار السعودية التجريبية + السنوي = 10 أشهر + تجربة 14 يومًا (حسب القرارات المعتمدة).
- TikTok DM وتسجيل المكالمات وميزات الذكاء الاصطناعي **معطّلة افتراضيًا**.
- منح وصول الدعم لا تتجاوز 24 ساعة وتتطلب سببًا.
- لا توجد في Control Plane أي جداول للعملاء أو المحادثات أو الرسائل (اختبار آلي).
